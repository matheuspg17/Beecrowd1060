# Beecrowd1060

## Descrição do problema
Faça um programa que leia 6 valores. Estes valores serão somente negativos ou positivos (desconsidere os valores nulos). A seguir, mostre a quantidade de valores positivos digitados.

## Como Funciona
1. O programa inicializa uma variável contadora (`controle = 0`).
2. Uma estrutura de repetição `for` é executada exatamente seis vezes para capturar cada um dos dados inseridos pelo usuário na variável `numeros`.
3. Dentro do laço, uma estrutura condicional `if (numeros > 0)` verifica se o valor atual é positivo.
4. Se a condição for verdadeira, a variável `controle` é incrementada em 1 (`controle++`).
5. Após o término do loop, o programa imprime o total acumulado formatado no console.
